The Ideation & Architecture

Why Typed Decisions Over Generative LLMs?

Routing, triage, safety guards, and content filtering don't need expensive token-by-token text generation.

⚡

7–15ms Decision Latency

Single-pass bidirectional inference replaces 1,500ms generative autoregressive loops. Decisions execute in real-time within interactive loops.

🎯

Formal Typing & Calibration

Strict schemas for choice (discrete categorical), score (ordinal ranking), and noul (epistemic confidence). No regex JSON parsing.

📦

50 MB Runtime vs 2,000 MB

Eliminates the entire PyTorch stack. Operates with only NumPy, Rust Tokenizers, and ONNX Runtime for instant serverless cold-starts.

Security & Integrity

Engineered to the OWASP Top 10: 2025

Audited for enterprise deployment in local agents and automated pipelines.

🛡️ Path Traversal Defense (CWE-22)

Rejects Windows backslashes (..\..), drive roots (C:\), and UNC network shares in subfolders, ensuring model weights never escape designated directories.

🔒 Thread-Safe Inference Sessions (CWE-362)

Lazy session initialization is protected by thread locks, ensuring high-concurrency web services serve simultaneous requests without memory corruption.

🌐 UTF-8 Locale Protection (CWE-754)

Enforces explicit UTF-8 decoding across all tokenizer configs and model metadata, preventing Windows ANSI (cp1252) crashes on international languages.
